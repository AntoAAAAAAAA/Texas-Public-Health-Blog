# Texas Public Health Blog

A personal blog-style website supported by original coding projects, visual explainers, and essays on healthcare access and public health disparities in Texas. While the site itself is built on **Weebly**, much of the content is backed by real Python-based data analysis.

## Live Site
**Visit here:** https://texaspublichealth.weebly.com/

## Purpose
This project serves to:
- Translate complex public health issues into accessible, student-friendly content
- Analyze and communicate key health disparities in Texas using data science tools
- Share personal reflections, learning moments, and community-centered storytelling

## What’s Included
- Essays on:
  - Food insecurity and economic inequality
  - Insurance coverage and healthcare deserts
  - Maternal health disparities
- Original data analyses built in Python:
  - **Charity_Table.ipynb** – summarizes local nonprofit resources
  - **Count_of_Facilities.ipynb** – maps out healthcare facility distribution
  - **Health_Searches.ipynb** – analyzes trends in health-related Google searches
  - **Mental_Health_Monitoring.ipynb** – explores emotional health survey data
- Infographics and visualizations shared alongside the essays

## Why This Matters
This blend of blogging and coding helps:
- Make public health issues more understandable to the average reader
- Promote data transparency and local relevance
- Train communication skills that mix storytelling with statistics

## Built With
- **Weebly** (site builder)
- **Python / Jupyter Notebooks** (data work)
- **Pandas / Plotly / Matplotlib / Seaborn** (visualization & analysis)
- Public datasets from Google Trends, Census, CDC, and state health sources
